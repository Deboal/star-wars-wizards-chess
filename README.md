# Dejarik: Star Wars 3D Wizard's Chess (Marble vs. Obsidian)

A playable single-file 3D Star Wars Wizard's Chess web application built with Material Design 3 standards and Three.js.

## Features
- **32 Sculpted Star Wars Characters:** White Carrara Marble (Light Side) vs. Volcanic Obsidian (Dark Side).
- **Choreographed Combat & Shatter Physics:** Custom idle, glide, lightsaber swing, blaster bolt, and kinetic stone-shatter animations.
- **Self-Contained FIDE Chess Engine & Sith Droid AI:** Full legal move validation, castling, en passant, check/checkmate, and AI opponent.

## Quick Deploy (Antigravity / Netlify / GitHub Pages)
- **Netlify Drop:** Drag this unzipped folder straight into https://app.netlify.com/drop
- **Netlify CLI:** Run `npx netlify-cli deploy --prod --dir=.`
- **GitHub CLI:** Run `gh repo create star-wars-wizards-chess --public --source=. --remote=origin --push`
